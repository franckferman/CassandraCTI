Sources

Eight threat intel
sources, ready to go.

Eight sources across five providers, generic RSS/Atom feeds, the ransomware.live family (victims, plus Cyber Press · SEC 8-K · Tracker Stats on its PRO tier), Red Flag Domains, CISA KEV vulnerabilities and abuse.ch IOCs. Every fetch is TLS-verified by default (opt out with CTI_TLS_NO_VERIFY=1 behind a proxy); the PRO feeds authenticate with ${RANSOMWARE_API_KEY}.

📰
RSS / Atom Feeds
source_id → rss:{name}

Polls any RSS or Atom feed with custom User-Agent. HTML stripped via BeautifulSoup, dates normalized to UTC. Fine-grained routing per feed via rss:{name} identifiers.

Ransomware Live
source_id → ransomware.live

Ransomware-group victim disclosures via a resilient multi-backend chain: PRO API (api-pro.ransomware.live, X-API-KEY) → free API v2 → legacy posts.json. Stable permalink keeps dedup identity across fallbacks. Country flag emoji auto-detected; configurable lookback window.

victim group_name country 🇫🇷🇬🇧🇺🇸 activity website discovered infostealer data_size
🚩
Red Flag Domains
source_id → red.flag.domains

Downloads the daily malicious domain list. One event per run with a 50-domain preview and a direct link to the full list.

daily .txt file domain count 50 preview full list link
🛡️
CISA KEV
source_id → cisa.kev

The CISA Known Exploited Vulnerabilities catalog, CVEs confirmed exploited in the wild. A single public JSON feed, no API key. Feeds the dashboard's Vulnerabilities tab; CVEs used in ransomware campaigns are flagged.

cve vendor product due_date ransomware_use no key
🦠
abuse.ch IOCs
source_id → abuse.ch

Malware-infrastructure IOCs across four abuse.ch feeds, Feodo (C2 IPs) and URLhaus (malware URLs) are public; ThreatFox (mixed IOCs) and MalwareBazaar (sample hashes) unlock with one free ${ABUSECH_API_KEY}. Feeds the dashboard's IOCs tab.

ioc ioc_type malware confidence feodo · urlhaus threatfox · malwarebazaar
📣
Cyber Press
source_id → ransomware.press · PRO

Recent cyber-press news articles from the ransomware.live PRO API (/press/recent). PRO-only, degrades gracefully to nothing without an api_key. Optional ISO-2 country filter.

victim summary country date
🏛️
SEC 8-K Filings
source_id → ransomware.8k · PRO

US public companies disclosing cyber incidents to the SEC, surfaced via the ransomware.live PRO API. PRO-only. Each event links to the real SEC / EDGAR filing. Item 1.05 = Material Cybersecurity Incident, Item 8.01 = Other Events.

company stockticker file_date EDGAR link item105 item801
📊
Tracker Stats
source_id → ransomware.stats · PRO

One daily digest summarising the ransomware.live tracker, victims tracked, active groups and press-article counts. PRO-only. Dedup identity includes the day, so you get exactly one digest per day.

victims groups press last_update one digest / day

CLI Reference

One tool to rule
the full lifecycle.

Init, run, debug, repair, everything from a single cassandra command.

cassandra init
Create default config in ~/.config/cassandra-cti/. First step on any new machine.
cassandra quickstart
Zero to running in one command: scaffold the config and open the live dashboard.
cassandra run
Execute the aggregation cycle. --loop for daemon mode, --web for the dashboard, --dry-run to test.
cassandra add-source
Enable a source: rss, ransomware_live, redflag, kev, abusech.
cassandra import-feeds
Bulk import RSS feeds from CSV. Format: Name,URL,Tags.
cassandra add-connector
Register a connector: --type teams / discord / telegram / smtp / web / signal.
cassandra routes-add
Route by source, tag, regex or entity name (include_terms) to transport(s); the connector auto-activates.
cassandra briefing-add / run
Periodic LLM digests: a prioritised recap or a ranked top_n per category, sent after the alerts.
cassandra remove-source / connector
Drop an RSS feed or a connector; routes-remove / briefing-remove too.
cassandra doctor
Validate YAML schema or fire a test message through any connector.
cassandra list
Print all configured sources, routes, and connector IDs.
cassandra service install
Install a systemd or OpenRC service so the loop survives crashes and reboots.
cassandra backfill
Replay historical events to a transport, recover from downtime.
cassandra db-reset
Delete the SQLite database. Clears all dedup history. Requires --force.
cassandra seen-clear
Surgically clear dedup history by source prefix, date range, or both.
Get Started

From zero to alerts
in five minutes.

01
Install

Clone and install. The cassandra CLI entry point is available globally after install.

$ git clone https://github.com/franckferman/CassandraCTI.git
$ cd CassandraCTI && pip install .
02
Initialize

Create default config files. Edit them, or use CLI commands to populate them.

$ cassandra init
# → ~/.config/cassandra-cti/config.yaml
# → ~/.config/cassandra-cti/connectors.yaml
03
Add connector & sources

Register your webhook. Add feeds. Enable trackers. Or copy a ready-to-run scenario from the examples directory (Discord, Teams SOC, Signal, entity-watch, category digests, and more).

$ cassandra add-connector \
    --id "teams-soc" \
    --webhook-url "https://..."

$ cassandra add-source rss \
    --name "CERT-FR" \
    --url "https://cert.ssi.gouv.fr/alerte/feed/" \
    --tags "cert,fr"

$ cassandra add-source ransomware_live
04
Validate & run
$ cassandra doctor config
$ cassandra doctor connector --id teams-soc
$ cassandra run --dry-run --verbose

# Go live, loop every 5 minutes
$ cassandra run --loop --interval 300
config.yaml, minimal example 
schema_version: 1

sources:
  rss:
    enabled: true
    feeds:
      - name: "CERT-FR Alertes"
        url: "https://cert.ssi.gouv.fr/alerte/feed/"
        tags: ["cert", "fr"]
  ransomware_live:
    enabled: true
    lookback_days: 30

transports:
  use: ["teams-soc"]

routes:
  - name: "cert-alerts"
    include_tags: ["cert"]
    transports: ["teams-soc"]

  - name: "ransomware"
    include_sources: ["ransomware.live"]
    transports: ["teams-soc"]
    template: "templates/ransomware_card.j2"

store:
  sqlite_path: ".cassandra_cti.db"
  seen_ttl_days: 90
Docker Compose 
services:
  cassandra-cti:
    build: .
    volumes:
      - ./config:/config
    environment:
      - MSTEAMS_WEBHOOK_SOC=${MSTEAMS_WEBHOOK_SOC}
      - DISCORD_WEBHOOK_URL=${DISCORD_WEBHOOK_URL}
    command: >
      cassandra run
        --config /config/config.yaml
        --loop --interval 300
    restart: unless-stopped
